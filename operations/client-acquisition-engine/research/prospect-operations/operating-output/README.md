# Prospecting Operating Output

Generated by `scripts/outreach_engine.py`.

All files are draft-only preparation artifacts. Nothing in this folder authorizes a CRM import, Gmail draft, send, enrollment, enrichment, campaign launch, or record deletion.

## Files

- `canonical-prospect-register.csv`: normalized 60-row staging register with stable IDs and dedupe keys.
- `hubspot-companies-import-preview.csv`: 11 company candidates absent from the live HubSpot domain set.
- `hubspot-contacts-import-preview.csv`: 18 contact candidates absent from the live HubSpot email set.
- `campaign-ready-batch.csv`: 12 priority and 3 test drafts with exact copy and no sending authority.
- `weekly-conversion-report.md`: current funnel and conversion baseline.
- `build-manifest.json`: validation, counts, and reconciliation record.

## Rebuild

```powershell
python scripts/outreach_engine.py
```

Use `--write-source` only when verified Gmail evidence should be promoted into the local staging CSV. The command is idempotent.
