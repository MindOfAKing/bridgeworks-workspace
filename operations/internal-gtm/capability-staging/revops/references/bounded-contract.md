# Bounded RevOps contract

Internal GTM roles consume these functions:

| Role | RevOps function |
|---|---|
| GTM Director | pipeline depth, capacity, priority, movement |
| Market and ICP Strategist | segment outcome patterns and commercial process fit |
| Data Steward | identity, duplicates, state-source ownership |
| Prospect Router | handoff completeness and next-action readiness only |
| Reply Intelligence | lifecycle interpretation and reply-to-next-action logic |
| Pipeline Manager | stage health, overdue action, stalled work |
| GTM Learning | stage conversion and outcome comparisons |

Excluded from this bounded adaptation: CRM mutation, workflow deployment, deal
desk authority, generic lead scoring, pricing, quota forecasting, and outbound
execution.
