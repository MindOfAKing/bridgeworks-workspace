# BridgeWorks design system

## HOW TO USE

1. Read `DESIGN.md` for visual rules.
2. Read `content-style.md` for voice, CTA, and evidence rules.
3. Load `tokens.json` in build or validation tooling.
4. Run `python scripts/validate_design.py <files>` before approving BridgeWorks output.

This package applies to BridgeWorks only. Do not apply it to Oliviks, CEEFM, church, event, MindOfAKing, or Emmanuel personal-brand work.

- `../knowledge/design.md`
- `../../business-brain/context/brand/bridgeworks/messaging-core.md`
